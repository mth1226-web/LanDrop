# LanDrop

同じWi-Fi/LANに繋がったWindows/Mac同士で、事前の共有設定なしにお互いを自動発見し、ドラッグ&ドロップだけでファイルを送受信できるデスクトップアプリです。

## 使い方

1. 各PCでLanDropを起動する（同じWi-Fi/LANに接続していること）。設定画面で「共有フォルダ」を確認・追加・削除できる（複数設定可能。デフォルトはドキュメント内の「LanDrop共有」フォルダ1つ）。設定画面のドロップゾーンにフォルダをドラッグ&ドロップするか、「フォルダを選んで追加」ボタンで追加できる
2. しばらくすると左のPC一覧に他の端末が表示される。一番上には自分自身も「（自分）」として表示される
3. PCを選ぶと、そのPCの共有フォルダの一覧（複数ある場合はフォルダアイコンが並ぶ）が右側に表示される。フォルダはクリックで移動でき、上部のパンくずで階層を戻れる
4. 共有フォルダの中に入った状態で、「アップロード」ボタンまたはファイル/フォルダのドラッグ&ドロップにより、選んでいるPCの共有フォルダに送り込める（自分のPCを選んでいる場合はローカルにそのままコピーされる）。フォルダをドラッグ&ドロップした場合も中身の階層構造ごと送られる（相手PCへはzipにまとめて送って向こう側で展開する）
5. 各項目のチェックボックスで複数選択でき、選択すると出てくる「選択した◯件をダウンロード」で、選んでいるPCの共有フォルダから自分の「ダウンロード保存先」（設定で変更可、デフォルトはダウンロードフォルダ）にまとめて取得できる。ファイルを1件だけ選んだ場合はそのままのファイル形式で、フォルダを含む場合や複数選択の場合はzipファイルとしてダウンロードされる（フォルダ内の階層構造は保持される）
6. 共有フォルダの中で「新しいフォルダ」でサブフォルダ作成、「名前変更」でファイル/フォルダのリネームができる（共有フォルダ一覧の階層自体は設定画面で追加/削除する）
7. 「自分のPC」を見ているときのフォルダ表示エリアには目印の色が付く。設定画面の「自分のPCのフォルダ表示エリアの色」からプリセットまたはカラーピッカーで自由に変更できる
8. 各項目の「詳細」ボタンから、ファイル/フォルダごとに色分け・メモ・「取り込み済み」チェック・「一覧から非表示」を設定できる（これは自分のPC内だけのローカルな整理情報で、相手のファイル自体やほかの人からの見え方は変わらない）。非表示にした項目は「非表示項目を表示」ボタンで一時的に再表示できる
9. ルート階層（共有フォルダ一覧）で各フォルダに「保存先を設定」ボタンがあり、そのフォルダからのダウンロード先だけを個別のローカルフォルダに変更できる（未設定のフォルダは共通の「ダウンロード保存先」に落ちる）
10. 「自分のPC」を見ているときは、項目をエクスプローラー等に直接ドラッグ&ドロップしてコピーできる（相手のPCのファイルは実体がこちらに無いためこの操作はできない）
11. ヘッダーの「チャット」ボタンから、同じLAN上のPCと文字でやり取りできる。「全体」タブは接続中の全PCへのブロードキャスト、それ以外のタブはPCごとの個別チャット。ログは「ログを削除」ボタンを押すまで消えず、アプリを再起動しても残る
12. ヘッダーの「プレビュー」ボタン、または一覧のプレビュー対応ファイル（画像・動画・音声・PDF・テキスト/コード系ファイル）をダブルクリックすると、別ウインドウでその場で表示できる（ダウンロードせずに中身を確認できる）。プレビューウインドウにはPCの外（エクスプローラー等）から直接ファイルをドラッグ&ドロップしても、その場でプレビューできる（この場合はアップロードされず、見るだけ）
13. フォルダ一覧の上部に「名前順」「日付順」「マニュアル」の並び替えボタンがある（全PC共通の設定）。名前順・日付順ではフォルダが常に先頭にまとまる。マニュアルを選ぶと各項目をドラッグ&ドロップして自由な順番に並び替えられる（↑↓ボタンでも移動可）。フォルダ/ファイルを区別せず並び替えでき、並び順はPCとフォルダごとにローカル保存され、相手には送られない（新しく増えた項目は名前順で末尾に追加される）。マニュアル並び替え中は、自分のPCの項目をエクスプローラー等へドラッグ&ドロップする操作はできない

共有フォルダは承諾なしで誰でも読み書きできるため（家庭内LAN等、信頼できるネットワークでの利用を想定）、公衆Wi-Fiなど不特定多数が同じネットワークに繋がる環境では使わないでください。

初回起動時にWindowsファイアウォール／macOSのローカルネットワークアクセス許可のダイアログが出た場合は許可してください（同じネットワーク上の端末を見つけるために必要です）。

## iPhone/Androidなどスマホから使う

専用アプリは無いが、各PCのLanDropは自分自身のHTTPサーバー上に簡易Web UIを持っているので、スマホのブラウザ
（Safari/Chrome等）から直接アクセスしてアップロード・ダウンロード・フォルダ作成ができる。設定画面の
「スマホから開く」に表示されるQRコードをスマホのカメラで読み取れば、そのままSafari等でLanDropの画面が開く
（同じWi-Fiに接続している必要がある）。URLは`http://<PCのLAN内IPアドレス>:<ポート番号>/`の形。
チェックボックスで複数選択してのダウンロード、フォルダごとのダウンロード（zip化）にも対応している。

Wi-Fiと有線LANなど複数のネットワークに同時接続しているPCでは、「スマホから開く」欄にWi-Fi/有線を選ぶ
プルダウンが表示され、QRコード/URLに使うIPアドレスを切り替えられる（デフォルトは自動選択）。隣に
「Windowsのネットワーク設定を開く」ボタンがあり、Wi-Fiの接続先切り替えなど、Windows標準のネットワーク
設定画面をそのまま開ける。

## 詳細モード（一覧表示のカスタマイズ）

フォルダ内一覧の表示切替を「詳細」にすると、ファイル名の羅列ではなく表形式で多くの情報を確認できる。

- 列: 状態・種類・ファイル名・拡張子・映像コーデック・解像度・総尺・容量・fps・ビットレート・音声コーデック
- 音声コーデック・ビットレート・総尺は、動画/音声ファイルを`music-metadata`（純JSライブラリ、ffmpeg等の外部バイナリ不要）で解析して埋める。**映像コーデック・解像度・fpsは現状「－」表示**（music-metadataは音声メタデータ中心のライブラリのため取得できない。埋めるにはffmpeg/ffprobeの同梱が必要だが、配布物のサイズ増加と配布手順の変更が必要になるため見送っている）
- 解析できるのは**自分の共有フォルダのファイルのみ**（相手PCのファイルは実体がローカルに無いため解析不可、「－」表示）
- サムネイル画像はプレビュー表示中のみ表示され、「－」「＋」ボタンでサイズを80〜400pxの範囲で調整できる

## フォルダ同期（片方向ミラー、Phase 1）

ヘッダーの「フォルダ同期」ボタンから、ローカルフォルダと相手PC（または自分自身）の共有フォルダとの間で片方向ミラー同期ができる。

- 同期ペアごとに名前・ローカルフォルダ・リモート端末/フォルダ・方向（push=ローカル→リモート、pull=リモート→ローカル）を設定して保存できる
- 「比較」で実際に変更する前に差分（作成/更新/削除件数と一覧）をプレビューできる。比較はサイズとmtime（2秒の許容誤差あり、FAT/NTFS対策）で行う
- 「同期実行」で確定。削除・上書きされる対象は既定でごみ箱へ移動する。ペアごとに「バージョン退避フォルダ（`.landrop-versions`）へ移動」に切り替えることも可能
- 削除を伴う同期は実行前に確認ダイアログが出る

## 重複チェック

ヘッダーの「重複チェック」ボタンから専用ウィンドウを開き、指定したフォルダ（共有フォルダに限らずPC上の任意のフォルダ・ドライブ丸ごとでも可）配下を再帰的に走査して、内容が完全に一致するファイル・フォルダを見つけられる。複数のフォルダ/ドライブを同時に指定すれば、それらをまたいで（クロスドライブで）重複を探せる。

- 判定方法: 同じサイズのファイル同士だけをSHA-256でハッシュ化して内容を比較する（サイズがユニークなファイルはハッシュ計算自体をスキップし、無駄な処理を避けている）
- 結果は2タブに分かれる
  - **完全一致**: 重複フォルダ・重複ファイルを、削減できる容量が大きい順に一覧表示。グループごとに番号バッジと色分けで見分けやすくしてある。あるフォルダが丸ごと重複と判定された場合、その配下のサブフォルダ・ファイルは冗長になるため個別には出さない
  - **似ているフォルダ**: 完全一致した重複フォルダの1つ上の階層同士を比較し、中身の一致率が50%以上あれば一致度%・共通ファイル数付きで表示する（例: 複数のプロジェクトフォルダの中に同じ構成のテンプレート/素材フォルダがコピーされているケースに気づける）。完全一致ではないため削除前に必ず目視確認が必要
- 各項目に「開く」「フォルダで表示」「1つ上を開く（親フォルダを開いて手動で階層を遡って確認できる）」「ごみ箱へ移動」ボタンがある。**削除は完全に手動**で、自動削除は一切行わない
- 相手PCのファイルは実体がローカルに無いため解析対象外（「－」表示）

【技術的な注意点（保守者向け）】
- 1ファイルの読み込みには30秒のタイムアウトを設けている。Google Drive/OneDriveなど「オンラインのみ」ファイルを持つクラウド同期ドライブでは、読み込み時にダウンロードが走って無期限に待たされることがあるため
- 「フォルダで表示」は、Windows標準の`shell.showItemInFolder()`ではなく`explorer.exe /select,`を直接起動する自前実装（`revealInFileManager`関数）にしている。`shell.showItemInFolder()`はWindows上で同期的にOS呼び出しを待つ実装で、対象がクラウド同期ドライブ上だと列挙に時間がかかり、**メインプロセスの他のIPC処理まで巻き込んで全ボタンが反応しなくなる不具合があった**ため（既存の共有フォルダ側の「フォルダで表示」も同じ実装に修正済み）
- 複数ルート指定時は、内部的に各ルートを仮想的な最上位フォルダ（`#root0`、`#root1`…）としてまとめ、1本の木として重複判定ロジックを使い回している

```bash
npm install
npm run dev        # 開発モードで起動
npm run typecheck  # 型チェック
npm run test       # ユニットテスト（node --test、実ソケット/実HTTPサーバーでプロトコルを検証）

npm run package    # electron-builderでの配布用パッケージ作成（要Windows開発者モード。下記参照）
```

## 他のPCへの配布（Windows）

この開発環境では`electron-builder`が内部で使う`winCodeSign`パッケージの展開にシンボリックリンク作成権限が必要で、
一般ユーザー権限のままだと失敗する（Windowsの「開発者モード」を有効にするか管理者権限が必要）。そのため、
electron-builderを使わずに、Electron本体の`electron.exe`を`LanDrop.exe`にリネームし、ビルド済みアプリを
`resources/app`配下に配置する(Electron自体の標準規約: `resources/app`があればそれを自動的にロードする)方式で、
本物の単体exeとして動く配布物を作っている。

手順（このリポジトリのルートで実行、PowerShell）:
```powershell
npm run build

$dest = "dist-portable\LanDrop-Windows"
Remove-Item dist-portable -Recurse -Force -ErrorAction SilentlyContinue
New-Item -ItemType Directory -Force "$dest\resources\app" | Out-Null
Copy-Item node_modules\electron\dist\* $dest -Recurse
Rename-Item "$dest\electron.exe" "LanDrop.exe"
Copy-Item package.json "$dest\resources\app\"
Copy-Item out "$dest\resources\app\out" -Recurse

Compress-Archive -Path $dest -DestinationPath dist-portable\LanDrop-Windows.zip
```

配布先のPCでは、zipを展開して`LanDrop.exe`をダブルクリックするだけで起動する（インストール不要、npm/Node.js不要）。

**注意（保守者向け）**: 上記の通りnode_modulesは配布物に同梱しない。main/preloadで新しいnpmパッケージを使う場合は、`electron.vite.config.ts`の`externalizeDepsPlugin`の`exclude`にそのパッケージ名を追加し、ビルド時にバンドルへ含めること。追加を忘れると開発モード（`npm run dev`）では動くのに配布版（portable exe）でだけ動かないという不具合になる。例: `music-metadata`（詳細モードの映像/音声情報解析に使用）。

## アップデート機能（Windows）

ヘッダーの「アップデート」ボタン（またはメニューの ヘルプ→アップデートを確認）から、GitHub Releases
(`https://github.com/mth1226-web/LanDrop/releases/latest`)の最新版をワンクリックでダウンロード・展開・
入れ替え・再起動できる。仕組みは`src/main/updater.ts`:

1. GitHub Releases APIで最新タグ・アセット(`LanDrop-Windows.zip`)情報を取得し、`package.json`の`version`と比較
2. 新しければzipをダウンロードし、`extract-zip`で一時フォルダに展開
3. 実行中の`LanDrop.exe`が終了するのを待ってから、展開した新しいファイル一式を`robocopy`で現在のインストール
   フォルダ(実行中のexeがあるフォルダ)に上書きし、新しいexeを起動する`.bat`をバックグラウンドで起動してから
   アプリ自身は終了する

新しいバージョンを配布するときは、上記の配布手順でzipを作り直し、`package.json`の`version`を上げてから
`gh release create v<version> dist-portable\LanDrop-Windows.zip --title ... --notes ...`でGitHub Releaseを
作成する（zipのアセット名は必ず`LanDrop-Windows.zip`にすること。updaterがこの名前で検索している）。

この自動更新は現時点でWindows版のみ対応。Mac版は下記の手順で手動ビルドする。

## 仕組み

- **端末発見**: 固定UDPポート(48737)へブロードキャストする自前のannounce/goodbyeメッセージのみで実現（mDNS/Bonjour等の追加依存なし）。ゲストWi-Fi等でクライアント分離（AP isolation）が有効なネットワークでは動作しません。
- **共有フォルダの参照・操作**: 各インスタンスがローカルにHTTPサーバーを立て、共有フォルダ配下に対する一覧取得・アップロード・ダウンロード・フォルダ作成・リネームのAPIを提供する。すべての操作は共有フォルダのルートより外に出られないようパス検証している（パストラバーサル対策）。承諾ダイアログ等は無く、共有フォルダとして設定した時点で同じLAN上の他PCから読み書き可能になる。

## 他のPCへの配布（Mac）

Windows上のこの環境にはmacOS版のElectronバイナリが無く、Mac向けビルドはWindowsからは作れない。
**Mac実機を用意し、そのMac上で**このリポジトリを`git clone`してから以下を実行する。

```bash
npm install
npm run package
# dist/mac/LanDrop.app ができる（package.jsonのbuild.mac.targetでdir+zipを指定済み）

# 署名なしのアプリはmacOSのGatekeeperに弾かれるため、ad-hoc署名を行う
codesign --force --deep --sign - dist/mac/LanDrop.app
```

`dist/mac/LanDrop.app`を他のMacにコピー(またはdist/mac-arm64/zipで固めたものを配布)すれば、
初回起動時は右クリック→「開く」でGatekeeperの警告を回避して起動できる。

macOS 15 (Sequoia)以降は、アプリがLAN上の他端末にアクセスする際に「ローカルネットワークへのアクセス」許可ダイアログが表示される。このダイアログは**未署名の`electron-vite dev`実行では安定して発火しないことがある**ため、上記のad-hoc署名を経たビルドで確認すること（Apple Developer登録や公証は個人利用の範囲では不要）。
