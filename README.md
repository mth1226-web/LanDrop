# LanDrop

同じWi-Fi/LANに繋がったWindows/Mac同士で、事前の共有設定なしにお互いを自動発見し、ドラッグ&ドロップだけでファイルを送受信できるデスクトップアプリです。

## 使い方

1. 送りたい端末と受け取りたい端末の両方でLanDropを起動する（同じWi-Fi/LANに接続していること）
2. しばらくすると左の「近くの端末」一覧に相手が表示される
3. 相手を選択し、ファイルをドロップゾーンにドラッグ&ドロップ
4. 受信側に確認ダイアログが出るので「受け取る」を押すと転送が始まる
5. 受信したファイルは設定画面で指定した保存先フォルダ（デフォルトはダウンロードフォルダ）に保存される

初回起動時にWindowsファイアウォール／macOSのローカルネットワークアクセス許可のダイアログが出た場合は許可してください（同じネットワーク上の端末を見つけるために必要です）。

## 開発

```bash
npm install
npm run dev        # 開発モードで起動
npm run typecheck  # 型チェック
npm run test       # ユニットテスト（node --test、実ソケット/実HTTPサーバーでプロトコルを検証）
npm run build      # ビルド
npm run package    # 配布用パッケージを作成（electron-builder）
```

## 仕組み

- **端末発見**: 固定UDPポート(48737)へブロードキャストする自前のannounce/goodbyeメッセージのみで実現（mDNS/Bonjour等の追加依存なし）。ゲストWi-Fi等でクライアント分離（AP isolation）が有効なネットワークでは動作しません。
- **転送**: 各インスタンスがローカルにHTTPサーバーを立て、①オファー（ファイル名・サイズのみ）→②受信側の承諾/拒否→③承諾時のみ実ファイルをストリーミング送信、という2段階方式。拒否時は何も書き込まれません。60秒応答がない場合は自動的にタイムアウトします。

## macOSでの最終確認について

macOS 15 (Sequoia)以降は、アプリがLAN上の他端末にアクセスする際に「ローカルネットワークへのアクセス」許可ダイアログが表示されます。このダイアログは**未署名の`electron-vite dev`実行では安定して発火しないことがある**ため、Mac実機での最終確認時は以下のようにad-hoc署名を挟んでからパッケージを起動してください（Apple Developer登録や公証は個人利用の範囲では不要です）。

```bash
npm run package
codesign --force --deep --sign - dist/mac/LanDrop.app
open dist/mac/LanDrop.app
```
